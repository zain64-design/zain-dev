(5): redux best practices

1: Dont perform side effect (timeout, date etc).our reducers fn should be pure fn koi bhi outside method jo is fn se outside hai usko access na kara jaye.yaha bus state ko update karne ka code and data transformation logic hoga.

2: no non serializable data means like string,array,boolean, dont use obj instance and class obj(js mein multiple obj hote hein jinka diff behaviour hota hai.redux mein obj hota hai jo store creat hota hai wo stringify hojata hai.jab bhi stringify karte hein to uska ref lost hojata hai)
exp:
const store = {date: new Date(), fn: function () {}};

const str = JSON.stringify(store);

const obj = JSON.parse(str);

console.log(obj,store)

3: Do note mutate state (redux-immutable-state-invariant)

4: dont import store directly in any nested comp only pass it in provider comp

5: redux recommend to store our data in obj form (incase agar hamaray passs array mein data hai or us mein kuch bhi find karna hai to hum ko by id to hum ko loop run karna hoga with out loop agar index nahi hai so we cant excess it. but by obj we can excess the data by using key(avoid un-necessary data traversing))

6: avoid putting form data in redux
